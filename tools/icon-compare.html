3 — Berwarna: 2D dan 3D 4 set

Ini kelompok yang benar-benar berwarna. Semuanya berasal dari set emoji, bukan dari pustaka ikon UI — itu sebabnya bentuknya terasa seperti ilustrasi, bukan seperti glyph. Fluent Emoji yang paling terasa 3D karena memakai gradien; Twemoji yang paling datar dan tajam. Konsekuensinya: emoji hanya punya satu warna, jadi tidak bisa mengikuti warna teks seperti ikon biasa.

Catatan lisensi. Kalau nanti dipakai di aplikasi, Fluent Emoji permissive (MIT), Noto OFL-1.1, tapi OpenMoji (CC BY-SA 4.0) dan Twemoji (CC-BY 4.0) mewajibkan atribusi — OpenMoji juga share-alike. Untuk pengiriman produk, pakai Fluent Emoji atau Noto dulu.

Cara baca. Sel berborder putus-putus berarti set itu tidak punya ikon dengan nama yang sama, jadi yang ditampilkan adalah pasangan terdekat — ini memengaruhi penilaian, bukan hanya tampilan. Skor mengukur kesamaan koordinat path Lucide→Tabler; skor rendah tidak berarti tampil beda (check berskor 0.00 tapi tetap centang yang identik). Yang menentukan adalah kelompok, bukan skor.
Catatan grid. Semua sel dikunci ke kotak 22 px yang sama, tapi tiap set menggambar di grid aslinya sendiri — Bootstrap dan Gravity 16×16, mayoritas 24×24, Phosphor 256×256, Material Symbols 960×960. Akibatnya ikon dari grid 16×16 terlihat lebih kecil dan lebih ringan di dalam kotak yang sama. Ini memengaruhi penilaian ukuran, bukan hanya bentuk.
Catatan Material Symbols. Paket itu memakai viewBox="0 -960 960 960" dan glyph terisi, bukan stroke 24×24, jadi ukurannya terasa jauh lebih besar daripada ikon lain di tabel ini.
Catatan Solar. Folder Broken dan Bold-Duotone tidak menyediakan nama polos untuk centang, jam, menu, musik, sampah, dan tutup. Yang tampil adalah varian terdekat (Check Circle, Clock Circle, Hamburger Menu, Music Note 2, Trash Bin Minimalistic, Close Square). Ikon tambah dan kurang juga berbagi satu file bernama Plus, Minus.svg.
Sumber. Lucide dari aset ter-build sebelumnya, Tabler dari src/icons/tabler/index.js. Sisanya disalin dari paket npm lalu paketnya dilepas lagi, jadi repo tidak punya dependensi ikon sama sekali.
